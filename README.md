\ AI Multimodal Medical Diagnostic Assistant



An AI-based clinical decision-support system designed to assist with

medical information gathering, differential diagnosis, and evidence-based

clinical reasoning.



\ Current Status



Phase 1 — Foundation



\ Technology Stack



\- Python

\- FastAPI

\- PostgreSQL

\- React + TypeScript

\- PyTorch / scikit-learn

\- RAG

\- Docker



\ Safety



This project is intended as a clinical decision-support prototype.

It is not designed to replace qualified healthcare professionals

or provide autonomous medical diagnosis.
